# Unit 3 Discussion: List Operations

## Overview

This assignment examines insertion, deletion, and searching in Python lists.

## Learning Objectives

- Insert values into a list
- Delete values from a list
- Search for values in a list
- Analyze list behavior and performance

## Requirements

1. Test insertion at the beginning, middle, and end.
2. Test deletion at the beginning, middle, and end.
3. Search for existing and missing values.
4. Demonstrate edge cases.
5. Create a real-world scenario.

While completing this assignment, I learned more about how Python lists work and how inserting, deleting, and searching for values affects the list. One thing I found interesting was how existing elements shift positions when something is added or removed. I also learned how important it is to validate indexes before deleting items to prevent errors.

One challenge I encountered was understanding how to properly insert and delete values at different positions without affecting the rest of the list. I worked through this by testing each operation at the beginning, middle, and end and checking how the list changed after each step. Using an aviation-related example helped me connect the concepts to something I am familiar with.

In aviation, lists could be used to organize flight plans, checklists, weather information, or flight schedules. For example, a pilot may need to add a new step to a flight plan, remove an outdated item, or search for specific flight information. Performance matters because larger lists take more time to process. Inserting or deleting items near the beginning requires other elements to shift, while searching may require checking each item individually. Understanding this helps when building programs that need to organize information efficiently.
