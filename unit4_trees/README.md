# Unit 4 Discussion: Binary Search Trees

## Overview

This assignment introduces Binary Search Trees (BSTs) and recursive tree operations.

## Learning Objectives

- Build a BST
- Insert values recursively
- Search recursively
- Perform in-order traversal
- Understand BST organization

## Requirements

1. Build a BST.
2. Insert multiple values.
3. Demonstrate in-order traversal.
4. Test searching.
5. Demonstrate edge cases.
6. Create a real-world BST example.

For this assignment, I learned how to build and work with a Binary Search Tree (BST), including inserting values, searching for specific values, and performing in-order traversal. I used an aviation flight plan as my example and created my own aircraft call signs to make the project more interesting and relatable to my aviation interests. One challenge was understanding how recursive methods move through the tree and knowing when to go left or right. I worked through this by following how each call sign was compared to the current node and adding comments to explain the process.

I learned that a BST organizes values so smaller values go to the left and larger values go to the right. This makes searching more efficient because it eliminates parts of the tree instead of checking every value. Compared to a list, which may require checking each item individually, a balanced BST can find values much faster. I also learned how in-order traversal produces sorted results. Overall, this assignment helped me better understand how data structures organize information and how they can be applied to real-world examples like organizing aircraft in a flight plan.
