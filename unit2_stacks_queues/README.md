# Unit 2 Discussion: Stacks and Queues

## Overview

This assignment explores two fundamental linear data structures:

- Stack (LIFO)
- Queue (FIFO)

## Learning Objectives

- Implement stack operations
- Implement queue operations
- Understand LIFO and FIFO behavior
- Create edge cases

While completing this assignment, I learned how stacks and queues work and how they can be used in real-world situations. I learned that a stack follows LIFO, meaning the last item added is the first one removed, while a queue follows FIFO, meaning the first item added is the first one removed. I also learned how to use methods like push (), pop (),etc. in Python.

One challenge I encountered was figuring out how to handle situations when a stack or queue was empty. I overcame this by using if statements to check whether the structure was empty and raising an error if someone tried to remove or view an item that wasn't there. Testing these situations helped me understand why edge cases are important.

I used aviation examples to better understand how these data structures could be useful. A stack could be used to keep track of flight-plan changes, where the most recent change would be undone first. A queue could be used to organize aircraft waiting for maintenance inspections in the order they arrived. Overall, this assignment helped me understand that stacks and queues serve different purposes depending on how information needs to be organized and accessed.
